# Power Academia

Aplicativo local para Windows, em português, para cadastro de alunos e controle de mensalidades.

- Cadastro, edição, desativação e exclusão de alunos.
- Mensalidades em atraso, vencendo hoje e nos próximos sete dias.
- Histórico de pagamentos, exportação para Excel e backups locais.
- Temas claro e escuro com a preferência salva.
- Versões de 32 e 64 bits e instalador que escolhe automaticamente a versão adequada.

[Documentação e instruções](Academia/README.md) · [Compilações Windows](https://github.com/Miramontes1985/douglaswindows/actions)

Os dados ficam no computador do usuário. Este repositório contém o código do aplicativo e cadastros fictícios usados na prévia e nos testes.
